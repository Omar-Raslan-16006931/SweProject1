## Optional bonus requirements

Not implemented in Milestone 1 (mandatory requirements are prioritised, PDF section 12):

- **ACC-02** (Accounts & Admin): The system shall send a verification link by email after registration and block booking until the email is verified.
- **ACC-07** (Accounts & Admin): The system shall allow a user who forgot their password to request a reset link by email; the link expires after 30 minutes, is single-use, is invalidated by a newer request, and the response does not reveal whether the email exists.
- **GEN-01-B** (Cross-cutting): The system shall also send the GEN-01 notifications (plus moderator invitations) by email via SMTP, using a test inbox in development.
- **FLT-27** (Flights): The system shall allow a registered user to change a Confirmed flight booking's date or flight (same route and cabin), paying any fare difference via Stripe or receiving a refund of a lower fare, subject to seat availability.
- **FLT-28** (Flights): The system shall allow seat selection.
- **HTL-26** (Hotels): The system shall allow a hotel moderator to reply to a review.
- **ITN-27** (Itineraries): The system shall allow booked flights and hotels to be linked to itinerary days, feeding the budget.
- **ITN-28** (Itineraries): The system shall allow a user to export or print an itinerary as PDF.
- **BLG-13** (Blog): The system shall allow an author to attach an itinerary to a post.
- **BON-01** (Accounts & Admin): The system shall provide an admin analytics dashboard showing bookings and revenue per provider over a selected period.
- **BON-02** (Cross-cutting): The system shall allow a registered user to save hotels and public itineraries to a favourites list and view it.
